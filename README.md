# 畅有趣小游戏（changyouqcom）

> 一套开源的 H5 网页小游戏合集平台，无需下载、打开即玩。收录了 80+ 个纯前端小游戏，涵盖益智、动作、射击、消除、休闲、棋牌等多种类型。

在线演示：<https://www.changyouq.com>

## 项目简介

本项目是一个纯静态的小游戏合集网站，无后端、无数据库、无需构建，克隆下来就能直接运行。首页基于 Bootstrap + Material Dashboard 风格搭建，通过 iframe 加载各个游戏页面；每个游戏都是独立的静态页面（HTML/CSS/JS），可单独运行，也可以很方便地新增或删减游戏。

## 功能特性

- 🎮 内置 80+ 个 H5 小游戏，全部在线可玩
- 🗂️ 游戏分类导航：全部游戏 / 益智 / 动作 / 射击 / 消除 / 休闲 / 棋牌
- 📱 响应式布局，支持电脑和手机浏览器直接游玩
- 🧩 纯前端实现（HTML + CSS + JavaScript，部分游戏基于 jQuery / Canvas / Cocos Creator）
- 🚀 零构建、零依赖，任意静态服务器即可部署
- ➕ 易于扩展：新增一个游戏只需在 `yxmb/` 下添加目录并在分类页中注册

## 目录结构

```
changyouqcom/
├── index.html        # 平台首页（左侧分类导航 + 右侧 iframe 游戏区）
├── 404.html          # 404 页面
├── css/              # 全站样式（Bootstrap、Material Dashboard、Font Awesome 等）
├── js/               # 全站脚本（jQuery、Bootstrap、Material 等）
├── images/           # 游戏封面图 / Logo 等静态资源
├── link/             # 各游戏分类的列表页（0=全部，1~6 对应各分类）
└── yxmb/             # 游戏模板目录，每个子目录（1~81）是一个独立小游戏
```

## 本地运行

无需安装任何依赖，任选一种方式：

**方式一：直接打开**

直接用浏览器打开 `index.html` 即可（部分游戏若使用 Ajax 加载资源，建议用方式二）。

**方式二：本地静态服务器（推荐）**

```bash
# Python
python -m http.server 8080

# 或 Node.js
npx serve .
```

然后访问 <http://localhost:8080>。

## 部署

本项目是纯静态站点，可部署到任何支持静态文件托管的服务：

- GitHub Pages：仓库 Settings → Pages → 选择分支根目录
- Vercel / Netlify：导入仓库，无需配置构建命令
- Nginx：将根目录指向 `index.html` 所在目录即可

## 如何新增一个游戏

1. 在 `yxmb/` 下新建一个编号目录，例如 `yxmb/82/`，放入游戏文件并保证入口为 `index.html`；
2. 将游戏封面图放到 `images/` 目录；
3. 在 `link/` 对应分类页面中，仿照现有条目添加游戏卡片（标题、封面、链接指向 `yxmb/82/index.html`）。
